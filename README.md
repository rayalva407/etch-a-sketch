# Etch-A-Sketch
![Etch-A-Sketch](https://github.com/user-attachments/assets/3a937a0c-3ccb-4e7a-ab68-7c61e9bae0a4)

An implementation of Etch-A-Sketch using HTML, CSS, and JavaScript. Drag mouse around the board and color using any color or a randomized color scheme.

## Features

  - Ability to sketch by dragging the mouse cursor inside the board.
  - Choose from any color palette.
  - Allows for randomized color scheme, which makes the trail look like a rainbow.
  - Opacity effect makes the color opacity gradually darker as you sketch.
  - You can change the grid size to your liking. (Ex. inputting 100 would make a board size 100X100)
  
## How to Use
  1. A live preview is available [here](https://rayalva407.github.io/etch-a-sketch/)
  2. By default, the page will open and the color will be black.
  3. Drag mouse around the board to sketch.
  4. To change color select a color from the pallete and select submit.
  5. To change the board size input a number and click submit.
  6. You can check the randomize color or opacity effect as well if you would like and then click submit.
  7. To clear the board click on the red Clear Board button.
